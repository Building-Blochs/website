From parts to Orb

Print, wire, flash

1

Print the body

Print all seven parts from the repo. The base goes upside down; print the arrow slowly with a brim so it stays put. PLA is fine.

2

Wire the electronics

Three omni wheels on stepper motors drive the 160 mm sphere, fed by the HR8825 driver module and powered at 9 V through the USB-PD breakout. The stepper module needs a few connector modifications — see the repo notes.

3

Flash the firmware

Open the firmware in PlatformIO, select the m5stack-cores3 environment and upload. It's an Arduino / ESP32 project using LVGL for the touchscreen.

4

Drop in the sphere & go

Seat the sphere on the three wheels, add the arrow, and power up. The touchscreen runs standalone; connect a PC for the games.

!

Mind the chirality

Some Orbs end up wired left-handed. If 90° rotations feel "wrong", start the game software with --invert-y-axis.

⚠

Connector modifications

The HR8825 stepper-driver module needs minor connector rework before it fits this build. Check the repository before you solder.
