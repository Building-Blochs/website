Theme switches on <body>

Radius, shadow language, border weight and the hand-drawn notes are all token-driven. Set data-vibe="playful|editorial|bold" and data-surface="warm|bright|slate" on <body> to reshape the whole site. This page renders the default playful / warm combination.

Layout chrome

Nav & footer

↑ live at the top · live at the bottom ↓

These come from the default layout (_includes/nav.html and _includes/footer.html), so the live examples are the sticky nav at the top of this page and the footer below it.

Nav

  • .site-nav — sticky, blurred, ink-bordered bar.
  • .brand — logo mark + .bn wordmark.
  • .nav-links a — underline-on-hover; .active marks the current page (set via the layout script + data-nav).
  • .nav-links a.pill — the dark rounded GitHub button.

Footer

  • .site-foot — ink-bordered footer, three columns.
  • .fcol.fbrand — wordmark + blurb; other .fcols are link lists under an h5 label.
  • .partners — optional inline partner row.
  • .foot-bottom — the thin mono baseline strip.
